# 岁悦里俱乐部 · 运营后台设计规范

> 适用范围：`admin/` 运营后台（Vue 3 + Vite）。本文档约定后台的视觉、布局、组件、交互与状态枚举，后续所有页面和改动都应遵循本规范，保持统一。

## 1. 设计原则

1. 效率优先：运营后台面向平台运营人员，以「看得清、找得到、操作快」为目标，信息密度可高于 C 端小程序。
2. 一致性：同一类操作、同一类状态，在全局使用相同的颜色、文案和交互。
3. 高风险必须确认：清退主理人、修改归属、调整佣金、退款、打款等不可逆操作，必须二次确认并记录日志。
4. 可追溯：所有关键写操作写入「操作日志」，日志包含操作人、时间、动作、详情、原因。
5. 状态可见：所有业务对象的状态必须用「文字 + 颜色标签」双重表达，不能只靠颜色。

## 2. 布局结构

后台采用「左侧固定导航 + 右侧内容区」的经典双栏布局。

- 左侧侧边栏宽度：`210px`，固定不随内容滚动。
- 右侧内容区：`flex: 1`，内边距 `24px`，可滚动。
- 侧边栏顶部为产品名「岁悦里 · 运营后台」。

```text
┌─────────────┬────────────────────────────────┐
│  岁悦里      │  数据看板 / 活动管理 / 订单...    │
│  · 运营后台  │                                │
│             │  ┌──────────────────────────┐  │
│  数据看板    │  │  内容卡片 / 表格 / 表单     │  │
│  活动管理    │  └──────────────────────────┘  │
│  订单/退款   │                                │
│  用户管理    │                                │
│  ...        │                                │
└─────────────┴────────────────────────────────┘
```

## 3. 色彩规范

### 3.1 品牌与功能色

| 用途 | 色值 | 说明 |
| --- | --- | --- |
| 主色 Primary | `#c25e3d` | 品牌橙红，用于主按钮、选中态、强调数字 |
| 主色浅底 | `#fdeee9` | 主色的浅色背景，用于橙色标签 |
| 主色深字 | `#9e4428` | 浅底上的深色文字 |
| 成功 Success | `#2f7d5c` | 已完成、已到账、正常 |
| 危险 Danger | `#d74a4a` | 删除、清退、拒绝、退款等破坏性操作 |
| 信息 Info | `#3b6fa0` | 分类、主理人审核等中性强调 |

### 3.2 中性色

| 用途 | 色值 |
| --- | --- |
| 页面背景 | `#f5f6f8` |
| 卡片背景 | `#ffffff` |

| 侧边栏文字 | `#c8cdd3` |

| 边框 / 分隔线 | `#e7e9ec` |

### 3.3 状态标签色（tag）

| 状态 | 背景 | 文字 |
| --- | --- | --- |
| 正常 / 上架 / 已完成 / 已到账 / 有效 | `#e7f3ee` | `#2f7d5c` |

规则：所有状态标签必须同时出现「状态文字」和「颜色背景」，不允许只显示彩色圆点。

## 4. 字体规范

- 字体族：`-apple-system, BlinkMacSystemFont, "PingFang SC", "Microsoft YaHei", sans-serif`
- 字号：
  - 页面标题 `h1`：`22px`
  - 卡片标题：约 `16px`
  - 表格正文：`14px`
  - 表头：`14px`，`font-weight: 600`
  - 表单 label：`13px`，颜色 `#6f747b`
  - 侧边栏导航：`15px`
- 数字强调（统计卡数值、金额）使用主色 `#c25e3d`，`font-weight: 800`。

## 5. 间距规范

- 内容区内边距：`24px`
- 卡片内边距：`18px`
- 卡片圆角：`12px`
- 卡片阴影：`0 6px 20px rgba(26,34,45,.05)`
- 统计卡间距：`12px`
- 表格单元格内边距：`10px 12px`
- 按钮内边距：`7px 14px`，圆角 `8px`
- 输入框内边距：`10px 12px`，圆角 `8px`

## 6. 组件规范

### 6.1 按钮

| 类型 | class | 样式 |
| --- | --- | --- |
| 主按钮 | `.btn.btn-primary` | 背景 `#c25e3d`，白字 |
| 次按钮 | `.btn.btn-ghost` | 白底 + `1px #d7dae0` 边框，深字 |
| 危险按钮 | `.btn.btn-danger` | 背景 `#d74a4a`，白字 |

按钮文字使用动词短语：`新建活动`、`通过`、`拒绝`、`打款`、`解绑`、`导出 CSV`、`保存`、`取消`。

### 6.2 表格

- 表头背景 `#fafafa`，文字 `#6f747b`。
- 行分隔线 `#e7e9ec`。
- 操作列按钮之间间距 `6px`。
- 长文本（标题、内容）允许换行，不强制省略；订单号、金额保持单行。

### 6.3 表单

- label 在输入框上方，`13px`、`#6f747b`。
- 输入框、下拉框、文本域统一 `.input` 样式：白底 + `1px #d7dae0` 边框 + 圆角 `8px`。
- 文本域用于 JSON 等高级编辑时，最小高度 `100px`。

### 6.4 弹窗（Modal）

- 遮罩 `rgba(20,22,26,.45)`。
- 弹窗白底、圆角 `14px`、内边距 `22px`、宽度 `520px`，内容过多时 `max-height: 90vh` 内滚动。
- 底部操作按钮右对齐，间距 `10px`。

### 6.5 统计卡（Stat）

- 卡片白底，数值用主色大字，标签用 `13px` 灰字。
- 响应式排列：`flex-wrap`，每张最小 `150px`。

## 9. 交互规范

1. 进入页面显示「加载中…」，加载完成后渲染内容。
2. 列表页顶部提供关键词搜索框；订单额外提供状态筛选下拉。
3. 破坏性操作（删除、清退、解绑、退款、打款拒绝）必须用 `confirm()` 或原因输入框二次确认。
4. 操作结果统一显示错误提示条（红色背景，位于内容区顶部）。
5. 导出功能：生成 UTF-8（带 BOM）CSV 文件，文件名按模块命名，如 `orders.csv`、`commissions.csv`。
6. 弹窗关闭方式：点击「取消」或遮罩关闭；提交成功自动关闭并刷新列表。
7. 高风险操作（调整佣金、变更归属、清退主理人、审核退款、审核提现）自动写入操作日志。
8. 空状态：表格无数据时显示「暂无数据」占位行，避免空白误读。

## 10. 命名与代码规范

- Vue 组件：`App.vue` 为单页入口，模块用 `v-if` 区块切换。
- API 层集中在 `src/api.js`，统一 `api.get/post/put/del` 方法，自动携带管理员 Token。
- 颜色、字号、间距尽量复用全局 `style.css` 中已定义的类（`.btn`、`.card`、`.tag`、`.input` 等），避免散落内联样式。
- 状态文案、枚举映射统一在脚本顶部定义（`categories`、`couponTypes`、`bindSource` 等），不硬编码在模板中。
