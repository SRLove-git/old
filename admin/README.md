# 岁悦里俱乐部 · 运营后台（Web）

基于 Vue 3 + Vite，对接 `/api` 后端接口。

## 启动

```bash
cd admin
npm install
npm run dev
```

开发服务器会把 `/api` 代理到 `http://127.0.0.1:3000`（需先启动 `server/` 后端）。

打开浏览器访问 Vite 输出的地址（默认 `http://localhost:5173`）。

## 模块

- 数据看板：活动/订单/客户/主理人统计、订单状态分布、累计佣金
- 活动管理：列表、新建、编辑、删除
- 直播管理：列表、新建、编辑、删除，归属主理人（私域）或平台公开，配置直播流/回放地址
- 订单管理：支付、取消、发货（快递公司+单号，或标记无需物流）、改物流、推进状态、退款；
  列表直接展示收件人/收货地址与快递单号，导出 CSV 含收货地址与物流字段
- 退款审核：用户申请退款后订单进入「退款中」，后台可直接「同意退款 / 拒绝退款」并填写原因；
  列表有「退款/售后」列展示原因、金额、申请时间与拒绝原因。是否走审核由规则配置里的
  「用户申请退款是否需要审核」开关控制
- 主理人审核：通过 / 拒绝（填原因）
- 主理人管理：冻结 / 解冻 / 清退
- 客户归属：解绑 / 修改归属
- 佣金管理：一键转可结算、单笔调整
- 提现审核：打款 / 拒绝
- 规则配置：全局分佣比例、最低提现、每月提现次数
