# 岁悦里俱乐部 · 运营后台（Web）

基于 Vue 3 + Vite，对接 `/api` 后端接口。

代码结构与开发规范见 [`docs/DEVELOPMENT.md`](../docs/DEVELOPMENT.md)。

## 启动

```bash
cd admin
npm install
npm run dev
```

开发服务器会把 `/api` 代理到 `http://127.0.0.1:3000`（需先启动 `server/` 后端）。

打开浏览器访问 Vite 输出的地址（默认 `http://localhost:5173`）。

## 模块

- 数据看板：活动/订单/客户/主理人统计、订单状态分布、累计佣金
- 活动管理、商品管理、学堂管理均支持平台自营。选择「平台自营」即可新建活动、商品或课程，无需先开通商户账号。为商家代发布时选择对应商家。
- 学堂管理支持编辑课程介绍和课节、设置直播流或回放地址。
- 签到/核销/补签：扫描或输入凭证码后核对订单，点击确认办理；课程补签可用姓名或手机号找到会员，选择计次卡、到课日期或已有课次，填写原因后扣 1 次。
- 订单管理：支付、取消、发货（快递公司+单号，或标记无需物流）、改物流、推进状态、退款；
  列表直接展示收件人/收货地址与快递单号，导出 CSV 含收货地址与物流字段
- 退款审核：用户申请退款后订单进入「退款中」，后台可直接「同意退款 / 拒绝退款」并填写原因；
  列表有「退款/售后」列展示原因、金额、申请时间与拒绝原因。是否走审核由规则配置里的
  「用户申请退款是否需要审核」开关控制
- 主理人审核：通过 / 拒绝（填原因）
- 主理人管理：冻结 / 解冻 / 清退
- 客户归属：解绑 / 修改归属
- 佣金管理：一键转可结算、单笔调整
- 提现审核：只能发起微信零钱商家转账或拒绝，支持查单、撤销与失败原因展示；到账与失败由微信回调/查单确认
- 规则配置：全局分佣比例、最低提现、每月提现次数
