# 快递公司目录

`logistics-carriers.json` 提供用户端手动选择快递公司所需的名称与编码，保存在后端，不打入小程序包。

- 来源：[快递鸟官方公司编码表](https://www.kdniao.com/file/%E5%BF%AB%E9%80%92%E9%B8%9F%E6%8E%A5%E5%8F%A3%E6%94%AF%E6%8C%81%E5%BF%AB%E9%80%92%E5%85%AC%E5%8F%B8%E7%BC%96%E7%A0%81.xlsx)
- 核对日期：2026-10-31。
- 来源工作表：国内。752 条非空名称/编码行，按去除两端空白后的编码去重为 733 条。
- 同一编码的多个公司名称以 ` / ` 连接，供搜索使用；编码保留官方大小写、下划线和连字符。
- 下载原文件 SHA-256：`1d9ef4996d346be66940b83c8f4a3f865efd1e8217057c7f9d2d284e0415f7e9`。

该表没有各产品的支持能力或套餐权限列，因此目录不代表全部公司已开通 `8002` 查询，也不能保证每个运单都有轨迹。更新目录时需继续核对来源、编码格式、重复编码别名及接口支持情况；不要直接混入国际专属产品目录。

查询参数依据：[快递鸟 8002 官方文档](https://www.kdniao.com/api-trackexpress)。顺丰需要时使用收/寄件手机号后四位；京东使用该运单发件方的青龙商家编码。外部单号查询不得借用本公司的全局青龙编码。
